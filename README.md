# Daugavpils, Latvia - Official City Website

## Description
This project is the official website for the city of Daugavpils, Latvia. The website provides information about the city, including its history, tourist attractions, upcoming events, and public transport options. It also features a photo gallery and a city tour video.

## Features
- **City Information**: Provides facts about Daugavpils, including population, region, founding year, and geographic location.
- **Historical Highlights**: Shares information about the city's historical significance.
- **Photo Gallery**: Displays images of various events and landmarks in the city.
- **City Tour Video**: Embeds a video tour of Daugavpils.
- **Weather Widget**: Shows the current weather conditions in the city.
- **Upcoming Events**: Lists upcoming events in Daugavpils with dates and times.
- **Public Transport**: Provides information about bus routes, the nearest train station, and intercity connections.
- **Tourist Routes**: Highlights popular tourist routes and attractions in the city.
- **Things to Do**: Lists various activities and places to visit in Daugavpils.

## Technologies Used
- HTML
- Tailwind CSS
- CSS
- JavaScript (for the weather widget)

## How to Use
1. **Clone the Repository**: Clone this repository to your local machine using `git clone <repository-url>`.
2. **Open the Project**: Navigate to the project directory and open the `index.html` file in your preferred web browser.
3. **Explore the Website**: Browse through the various sections of the website to learn more about Daugavpils and its attractions.
